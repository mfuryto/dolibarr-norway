# Norsk regnskapsoppsett fra 0.65.0

Åpne **Regnskap → Innstillinger → Norsk regnskapsoppsett**.

1. Velg norsk kontoplan med forhåndsvisning og bekreftelse.
2. Vurder kunde-/leverandørstandard og øvrige standardkontoer ut fra virksomheten.
3. Velg aktuelle MVA-satser og salg-/kjøpskontoer på satsradene.
4. Opprett nødvendige journaler og koble bankkontoen til riktig konto og journal.
5. Velg produktenes regnskapskoder og regnskapsperioder i kjernen.

Oppsetthjelperne fyller bare uttrykkelig bekreftede, støttede tomme valg.
Eksisterende valg og historikk skal gjennomgås manuelt og bevares.
Kontoenes eksistens avgjør ikke avgiftsbehandling, fradragsrett eller rapportering.

Daglig bokføring bruker kjernens fakturaer, kjøpsjournal og hovedbok.
Egne kontrollsider, kontrollkopier og særskilt kjøpsbokføring er fjernet.
Tidligere tilleggshistorikk kan leses fra modulinnstillingene når data finnes.

Se [samlet oppsettsveiledning](norwegian-setup-guide.md),
[kontoplan](norwegian-chart.md), [standardkontoer](standard-accounts.md),
[MVA-kontoer](vat-accounts.md) og [journaler](journal-setup.md).
Norsk MVA-rapportering, SAF-T og EHF er fortsatt uferdig.
