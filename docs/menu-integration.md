# Menyer og tilgang fra 0.65.0

Modulen legger til én menyinngang: **Regnskap → Innstillinger → Norsk
regnskapsoppsett**. Den samler norsk kontoplan, standardkontoer, MVA-kontoer
og lenker til kjernens innstillinger. Oppsett krever administrator.

Daglig arbeid bruker kjernens menyer for faktura, tilbud, varer/tjenester,
kjøpsjournal, hovedbok, perioder og bank. Ingen egne kontrollfaner eller
kontrollmenyer legges på dokumentene.

Oppsettsveilederen nås fra modulinnstillingene. Den viser forklaringer og
lenker uten egen fremdrifts- eller godkjenningsstatus. Nummerserier og
dokumentinnstillinger er samlet i steg 7.

Et skrivebeskyttet arkiv vises i modulinnstillingene bare når eldre
tilleggshistorikk finnes. Tilgang krever intern administrator og leserett
for regnskapet i aktivt foretak. Arkivet viser lagrede data, ikke nye
vurderinger eller godkjenninger. Tidligere sider og faner er fjernet.
