# Kunde- og leverandørkonto

Bruk **Regnskap → Innstillinger → Standardkontoer**. For den medfølgende norske
kontoplanen er 1500 Kundefordringer og 2400 Leverandørgjeld vanlige reservekontoer.
Kundens/leverandørens egne koblinger kan overstyre standarden.

Fra 0.77.0 er den separate utfyllingshjelperen fjernet. Lagrede valg beholdes.
Du bruker samme native skjema ved ny oppstart og senere endringer. Egne
kontonavn er tillatt. Endring flytter ikke hovedbokshistorikk, men kan påvirke
utstedte dokumenter som ennå ikke er overført til hovedboken.

Se [samlet grunnoppsett](accounting-setup.md) og [standardkontoer](standard-accounts.md).
